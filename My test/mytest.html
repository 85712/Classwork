Welcome to my webpage! This page teaches the basics of HTML, which stands for HyperText Markup Language.

1. Understanding HTML Tags

HTML tags tell the browser how to structure and display content.

Example: <p>Hello!</p>

  • Opening tag: <p>
  • Content: Hello!
  • Closing tag: </p>

An attribute gives extra information to an element. For example, in <a href="https://example.com">, href is the attribute name and the URL is its value.

Some elements are void elements and do not have closing tags. Examples include <br>, <hr>, and <img>. They may be written with a trailing slash, such as <br />, but HTML does not require it.

9. Connecting CSS

CSS controls the appearance of a webpage, including colors, fonts, spacing, and borders.

The link element in the head connects an external CSS file:
